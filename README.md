DOMINONA PIZZA KIOSK

Project Overview

Dominona Pizza Kiosk is a C# Console Application designed to make food ordering easier and more organized. Customers can choose their preferred order type, browse food categories, select products, enter quantities, and pay for their orders. The system also provides a cashier section where orders can be viewed and their statuses can be updated.

System Features

1. Customer

- Choose between Dine In and Take Out.
- Browse food categories: Pizza, Pasta, Chicken, Sides, Drinks, and Desserts.
- View available products and prices.
- Select products and enter quantities.
- Add products to the cart.
- View the order summary and total amount.
- Enter payment and receive the calculated change.
- View the printed receipt on screen.

2. Cashier

- View all customer orders.
- See order numbers, order types, products, quantities, and total amounts.
- Search for an order using its order number.
- Update order status to Preparing, Ready, or Completed.

3. Main Menu

- Access the Customer section.
- Access the Cashier section.
- Exit the application.

Technologies Used

- Programming Language: C#
- Application Type: Console Application
- Development Environment: Visual Studio

Project Files

The project is organized into the following C# files:

- "Program.cs" – Main program and navigation.
- "Product.cs" – Product information.
- "Menu.cs" – Food categories and product selection.
- "CartItem.cs" – Stores product and quantity information.
- "Cart.cs" – Handles cart operations and total calculation.
- "Order.cs" – Stores customer order details.
- "OrderService.cs" – Creates and manages orders.
- "Checkout.cs" – Handles payment and checkout.
- "Receipt.cs" – Displays the customer's receipt.
- "Cashier.cs" – Displays orders and updates their status.

System Requirements

- A computer or laptop
- Visual Studio
- .NET SDK compatible with the project

How to Set Up the Project

1. Open Visual Studio.
2. Select Open a Project or Solution.
3. Locate and open the Dominona Pizza Kiosk project file (".csproj").
4. Wait for the project to load.
5. Make sure all required C# files are included in the project.

How to Run the System

1. Open the Dominona Pizza Kiosk project in Visual Studio.
2. Set the project as the startup project if needed.
3. Click the Start button or press "Ctrl + F5".
4. Wait for the console window to appear.
5. The main menu will be displayed.

How to Use the System

Customer Process

1. Select Customer from the main menu.
2. Choose Dine In or Take Out.
3. Select a food category.
4. Choose a product and enter the desired quantity.
5. Continue selecting products or choose Checkout.
6. Review the cart and total amount.
7. Enter your payment.
8. Once payment is sufficient, the system displays the receipt.
9. The system returns to the main menu.

Cashier Process

1. Select Cashier from the main menu.
2. View the available customer orders.
3. Enter the order number you want to update.
4. Choose the new order status: Preparing, Ready, or Completed.
5. The system displays a confirmation message.
6. Return to the main menu when finished.

Exit Process

1. Select Exit from the main menu.
2. The system displays a thank-you message.
3. Press any key to close the application.

Limitations

- The system runs through a console interface.
- Orders are stored temporarily while the application is running.
- Saved orders are not retained after the application is closed.
- The system does not use an online payment service or database.
